# 第一人称钩爪（Grappling Hook）Demo

基于 **Godot 4.7** 的第一人称抓钩玩法演示：朝准心方向发射钩爪，命中场景中的锚点后生成绳索，玩家随之被拉向锚点并可在绳索约束下摆动、收绳加速、放绳坠落。

## 项目简介

- **玩法**：第一人称视角在场景中跑动 / 跳跃，用钩爪勾住墙壁、高塔、横梁或发光锚点，实现摆荡、上升与快速位移。
- **场景**：[scenes/main.tscn](scenes/main.tscn) 是一张手工搭建的测试关卡，包含地面、高墙、高塔、高空横梁、远处平台，以及三个发光锚点（`Level/Anchors/` 下的 `AnchorBeam`、`AnchorTower`、`AnchorPlatform`），用于验证不同角度、不同距离的钩爪手感。
- **实现范围**：门槛要求（发射命中 / 施加拉力 / 断开）已全部完成，进阶挑战完成 ★ 与 ★★。

## 操作说明

| 操作 | 按键 | 说明 |
| --- | --- | --- |
| 前后左右移动 | `W` `A` `S` `D` | 相对视角方向移动 |
| 跳跃 | `空格` | 仅在着地时生效 |
| 转动视角 | 鼠标移动 | 水平转动整个身体，垂直只转摄像机云台 |
| **发射钩爪** | `鼠标左键` | 朝准心方向做射线检测，命中即生成绳索并开始施加拉力 |
| **断开钩爪** | `鼠标右键` | 立即恢复自由状态，保留当前速度（可用来做荡跃甩出） |
| 收绳（持续） | `E` | 按住时绳索以 12 m/s 缩短，把玩家拽向锚点 |
| 放绳（持续） | `Q` | 按住时绳索以 14 m/s 伸长，绳索松弛后重新被重力支配 |
| 收绳 / 放绳（步进） | `鼠标滚轮 上 / 下` | 每格调整 1.5 m，适合精细控制绳长 |
| 释放鼠标 | `Esc` | 在「捕获 / 可见」之间切换鼠标模式，方便切出窗口 |

### 运行方式

**在编辑器中**：用 Godot 4.7 打开本项目，直接运行（主场景为 `res://scenes/main.tscn`）。

**从命令行**：

```bash
godot --path <项目目录>
```

## 技术选型

| 项 | 选择 | 理由 |
| --- | --- | --- |
| 引擎 | Godot 4.7（stable） | 开源、3D 场景搭建与调试成本低 |
| 语言 | GDScript | 与引擎节点 / 信号体系贴合，迭代快 |
| 渲染后端 | Forward+（D3D12） | 桌面端 3D 默认后端，光照表现足够 |
| 物理引擎 | **Jolt Physics** | Godot 4.7 的 3D 物理引擎选项，稳定性与角色运动表现优于默认 GodotPhysics |
| 玩家节点 | `CharacterBody3D` | 手感完全可控：输入驱动而非力驱动，不会被物理系统拖慢；配合 `move_and_slide()` 处理碰撞与斜坡 |
| 绳索约束 | **自写矢量约束**（非物理关节） | 见下 |

### 关键设计决策

**1. 用矢量计算实现绳索约束，而不是物理关节**

绳索被建模为一条「**只能绷紧、不能伸长**」的约束：每物理帧计算玩家到锚点的实际距离，超出当前绳长时按超出量施加指向锚点的拉力（`超出量 × 刚度`，并封顶），同时只在玩家**径向远离**锚点时施加阻尼以抑制来回振荡。

没有使用 `PinJoint3D` / `Generic6DOFJoint3D` 等物理关节组件，原因是：

- 玩家是 `CharacterBody3D`（运动学体），本身不参与关节求解，关节方案需要改用 `RigidBody3D` 玩家，代价是放弃直接控制手感；
- 收放绳会高频改变绳长，关节的约束长度突变时容易产生抖动与穿透；
- 自写约束可以顺手做「最大拉力封顶」「径向阻尼」这类手感调节项，参数全部暴露在 Inspector 里。

这套约束天然就是**以锚点为圆心、绳长为半径的摆动**：玩家被拉近到绳长以内后绳索松弛，切入自由落体并在切向速度的带动下绕锚点画弧，从而形成荡秋千的效果；收绳缩短半径即加速，放绳则增大半径或直接脱离约束。

**2. 外力注入的帧序**

钩爪通过 `Player.add_external_force()` 把拉力写入一个外力累加器，玩家在 `_physics_process` 里先消费外力再 `move_and_slide()`。为保证拉力在同一物理帧生效，钩爪节点的 `process_physics_priority` 被设为 `-1`，比玩家（默认 `0`）先执行——否则拉力会晚一帧生效，收绳手感会有明显延迟。

**3. 移动逻辑不覆盖外力速度**

玩家的水平移动采用「**只在输入方向上补足到 `move_speed`**」的策略：当玩家被钩爪拽到超过移动速度时，输入逻辑不会把速度拉回上限，只做方向修正。这样高速摆荡时不会出现「一按方向键就被拖慢」的割裂感。

**4. 绳索朝向的坐标系构造**

绳索用一根**单位高度圆柱**表示，靠节点 `Basis` 逐列缩放来同时控制粗细与长度。这里刻意避开了 `Basis.scaled()`——它按**行**缩放，会把长度错误地缩放到 Z 轴上，导致绳索方向恒为世界 Y 轴（表现为绳子永远垂直于地面）。当前实现显式构造一个 Y 轴对齐到绳索方向的右手坐标系，再分别缩放各列。

**5. 视觉与交互细节**

- 命中瞬间的绳长取实际距离的 85%（`initial_rope_slack`），保证钩住即绷紧、立刻起拉，而不是吊在原地不动；绳长下限 `min_rope_length` 避免把玩家贴到锚点上。
- 绳索材质带自发光，便于在暗色场景中辨识；准心用 `_draw()` 绘制并带深色描边，在浅色背景上同样清晰。
- 准心 `mouse_filter` 设为 `IGNORE`，不会吞掉发射钩爪的鼠标事件。

## 项目结构

```
├── project.godot              # 项目配置：输入映射、物理引擎（Jolt）、渲染后端
├── scenes/
│   ├── main.tscn              # 测试关卡：地面 / 高墙 / 高塔 / 横梁 / 平台 / 三个锚点 + 玩家
│   └── player.tscn            # 玩家：CharacterBody3D + 摄像机云台 + 钩爪 + HUD 准心
└── scripts/
    ├── player.gd              # 第一人称控制器：移动 / 跳跃 / 视角 / 外力注入接口
    ├── grappling_hook.gd      # 钩爪核心：发射命中、绳索约束与拉力、收放绳、断开
    └── crosshair.gd           # 屏幕中心准心（_draw 绘制，带描边）
```

### 主要可调参数

集中在 [scripts/grappling_hook.gd](scripts/grappling_hook.gd) 的 Inspector 导出分组中：

- **发射**：`max_range`（最大射程，默认 60 m）、`hookable_mask`（可钩物理层）
- **绳索约束**：`pull_force`（最大拉力）、`rope_stiffness`（刚度）、`rope_damping`（径向阻尼）、`max_pull_speed`（拉向锚点的限速）
- **收绳 / 放绳**：`reel_in_speed`、`reel_out_speed`、`reel_step`、`min_rope_length`、`initial_rope_slack`
